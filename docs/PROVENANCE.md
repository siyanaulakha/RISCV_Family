# Provenance

This repository unifies three previously separate RTL projects:

- `siyanaulakha/riscv`
- `siyanaulakha/Pipelined_RISC-V_RV32I`
- `siyanaulakha/risc_v_acs_version`

The original pipelined RV32I implementation was developed collaboratively.
Its original Git history and contributor attribution remain preserved in the
source repository.

Subsequent RTL auditing, regression infrastructure, corrections and unified
processor-family integration are maintained in this repository.
